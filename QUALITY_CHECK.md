# Qualitätsprüfung – Nombres FR 1.1

Stand: 25.11.2026

## Automatisierte Prüfungen

- 619 Aufgaben auf eindeutige IDs, nichtleere Lösungen und konsistente Datentypen geprüft.
- 531 Multiple-Choice-fähige Aufgaben jeweils 100-mal mit neu gemischten Optionen erzeugt.
- Insgesamt 53.100 Multiple-Choice-Sets geprüft.
- Ergebnis: 0 Sets ohne richtige Antwort; 0 Sets mit mehr als einer richtigen Antwort; 0 Sets mit doppelten Optionen.
- Kritische Kardinalzahlen separat geprüft: 0, 1, 17, 21, 61, 70, 71, 72, 79, 80, 81, 90, 91, 99, 100, 101, 180, 200, 201, 280, 281, 999, 1000, 1001, 2000, 2026, 10000.
- Kritische Ordnungszahlen separat geprüft: 1., 2., 3., 4., 5., 9., 21., 71., 80., 81., 91., 100.
- Telefonnummern bewahren führende Nullen in der Aussprache, z. B. 06 → « zéro six ».
